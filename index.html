Dashboard instellen

Minimaal 2, standaard 5. Hoger = rustiger voor een oude iPad.

Geldt voor alle kaarten. Kies bij een entiteit hieronder "Standaard" om deze maat te gebruiken, of een eigen maat.

Een groep krijgt een eigen titel boven zijn kaarten. Zet de titels hier in de volgorde waarin ze op het dashboard moeten staan en kies bij elke entiteit de groep waar hij bij hoort.

Schakelaar = tik aan/uit · Sensor = alleen weergeven · Knop = scene of script · Rolluik = open/dicht.
Het icoon kiest het dashboard zelf op basis van het soort entiteit; met Icoon zet je het vast.

Kies een entiteit om er meteen een kaartje voor toe te voegen.
